# Privacy Policy — Figranium for Dify

Last updated: 2026-09-02

Figranium for Dify does not collect telemetry, analytics, usage metrics, or persistent data.

When a user invokes a tool, the plugin sends only the configured Figranium API key and the tool request data (task ID and optional variable overrides) to the Figranium server URL configured by that Dify workspace. The plugin returns the server's JSON response to Dify and does not transmit it to any other service.

The Dify workspace administrator controls the Figranium server, its logging, retention, browser automation tasks, and any data those tasks process. Review Figranium's own deployment and privacy practices before enabling this plugin.
